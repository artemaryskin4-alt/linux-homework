# Nextflow Pipeline for Paired-End FASTQ Processing

## Описание
Этот код представляет собой Nextflow-пайплайн (DSL2) для обработки парных FASTQ-файлов. 
Пайплайн автоматизирует контроль качества, выравнивание на референсный геном, 
фильтрацию по качеству картирования (MAPQ) и создание индексов BAM-файлов.

## Этапы пайплайна
Согласно техническому заданию, пайплайн состоит из следующих модулей:
1. **Контроль качества (QC):** Запуск `FastQC` для каждого FASTQ-файла и агрегация отчетов с помощью `MultiQC`.
2. **Выравнивание (Alignment):** 
   - Построение индекса референсного генома с помощью `BWA-MEM2`.
   - Выравнивание чтений командой `bwa-mem2 mem` и сортировка результата в формат BAM (`samtools sort`).
3. **Фильтрация и индексация:**
   - Фильтрация BAM-файлов с помощью `samtools view` (оставляются только выравнивания с MAPQ >= порога).
   - Создание индекса `.bai` для отфильтрованных BAM-файлов с помощью `samtools index`.

## Параметры запуска
Все входные данные задаются через параметры командной строки:

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `--input` | Путь к файлу `samplesheet.csv` | `samplesheet.csv` |
| `--reference` | Путь к референсному геному (FASTA) | `test_data/genome.fa` |
| `--outdir` | Каталог для сохранения результатов | `results` |
| `--min_mapq` | Порог качества картирования (MAPQ) | `20` |

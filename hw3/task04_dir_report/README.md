# Задание 4: отчёт о файлах в директории

## Что делает
Скрипт `dir_report.sh` собирает статистику: сколько файлов каждого типа
в директории и их суммарный размер. Показывает топ-N самых больших файлов.

## Как запустить
    ./dir_report.sh [-r] [директория]

## Флаги
- `-r` — рекурсивно по подпапкам

## Переменные
- `TOP_N=10` — сколько больших файлов показать (0 = отключить)

## Пример вывода
    Тип               Файлов       Размер
    sh                     6      16.0 КБ
    txt                   10       6.7 КБ
    --------          --------    --------
    ИТОГО                 19      23.1 КБ

## Что было сложного
- `find -printf '%s %p\n'` для размеров
- `awk` для агрегации по расширениям
- Human-readable вывод (КБ, МБ, ГБ) через функцию в awk

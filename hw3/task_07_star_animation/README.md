# Задание 7: обратный отсчёт с анимацией

## Что делает
Скрипт `countdown.sh` ведёт обратный отсчёт от заданного числа секунд
до нуля. Каждую секунду выводит анимированную шкалу из звёздочек,
которая растёт, убывает или бежит «туда-обратно».

## Как запустить
    ./countdown.sh [секунды] [режим]

## Аргументы
- `секунды` — с чего начинать (по умолчанию 10)
- `режим` — одно из:
  - `grow`   — звёздочек становится больше (по умолчанию)
  - `shrink` — звёздочек становится меньше
  - `fill`   — шкала растёт до середины и обратно

## Переменные окружения
- `WIDTH=20`   — ширина шкалы в символах (по умолчанию 20)
- `DELAY=1`    — задержка между шагами в секундах (по умолчанию 1)
- `SYMBOL=*`   — символ для анимации (по умолчанию звёздочка)

## Примеры
    ./countdown.sh
    ./countdown.sh 5
    ./countdown.sh 10 shrink
    ./countdown.sh 8 fill
    WIDTH=30 SYMBOL=# ./countdown.sh 5
    DELAY=0.3 ./countdown.sh 15

## Пример вывода
Режим `grow`, 5 секунд, WIDTH=10:

    Обратный отсчёт: 5 сек (режим: grow, ширина: 10)

    [..........]  5 сек
    [**........]  4 сек
    [****......]  3 сек
    [******....]  2 сек
    [********..]  1 сек
    [**********]  0 сек

    Время вышло!

Каждая строка перерисовывается на месте — терминал показывает
одну бегущую шкалу, а не «лестницу».

## Что было сложного
- Перерисовка строки на месте: символ `\r` возвращает каретку
  в начало, но не переводит на новую строку
- Формула для расчёта длины шкалы: целочисленное деление в bash
  (`SECONDS_ARG - i` для режима grow, `i` для shrink)
- Форматирование `printf "%0.s$SYMBOL"` — трюк для вывода N символов
- Цвета: ANSI-escape последовательности, только если stdout — терминал
  (проверка через `[ -t 1 ]`)
- Встроенная переменная bash `SECONDS` — пришлось использовать
  другое имя (`SECONDS_ARG`)

## Как работает анимация
Ключевая строка:

    printf "\r${color}"; draw_bar ...; printf " %2d сек${NC}  "

- `\r` — возврат в начало строки (не в новую строку)
- дальнейший вывод «перезаписывает» предыдущее содержимое
- два пробела в конце — затирают остатки более длинного вывода

Это стандартный приём для прогресс-баров в CLI
(git clone, pip install, docker pull используют ту же технику).

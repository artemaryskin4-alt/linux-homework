# Задание 3: топ самых частых слов

## Что делает
Скрипт `top_words.sh` находит N самых частых слов в текстовом файле.
Поддерживает русский и английский, слова с дефисом, стоп-слова.

## Как запустить
    ./top_words.sh <файл> [N]

    STOPWORDS_FILE=stopwords_mixed.txt ./top_words.sh sample.txt
    KEEP_REGISTER=1 ./top_words.sh sample.txt
    MIN_LEN=4 ./top_words.sh sample.txt

## Переменные окружения
- `STOPWORDS_FILE` — файл со стоп-словами
- `KEEP_REGISTER=1` — учитывать регистр
- `MIN_LEN=4` — игнорировать слова короче N букв

## Файлы в папке
- `top_words.sh` — основной скрипт
- `sample.txt` — тестовый файл (англ. + русский)
- `sample.txt.bak` — резервная копия (можно удалить)
- `stopwords_*.txt` — списки стоп-слов
- `output_*.txt` — сохранённые выводы в разных режимах
- `run_top_tests.sh` — автотесты

## Что было сложного
- `tr` не понимает UTF-8 — заменили на `grep -oP "[\p{L}’'-]+"`
- Локаль: `C.utf8` вместо `C.UTF-8` в твоей системе
- Дефис в `[...]` — только в конце набора, иначе ошибка «invalid range»

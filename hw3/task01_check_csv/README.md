# Задание 1: проверка CSV/TSV ## Что делает
Скрипт `check_file.sh` проверяет, что во всех строках CSV или TSV файла
одинаковое количество столбцов. Расширение определяет разделитель
(`,` для CSV, `\t` для TSV).

## Как запустить
    ./check_file.sh <файл.csv|файл.tsv>

## Пример вывода
    Строка 1: 3 столбцов (эталон)
    Строка 2: 3 столбцов — OK
    Строка 3: ОШИБКА! Ожидалось 3, найдено 2
    ❌ Найдено ошибок: 1

## Файлы в папке
- `check_file.sh` — основной скрипт
- `good.csv` — корректный пример
- `bad.csv` — пример с ошибкой

# Задание 6: валидация и исправление CSV

## Что делает
Скрипт `task06_csv.sh`:

1. `tr` — заменяет разделитель `;` на `,`.
2. `awk` — проверяет валидность: в каждой строке должно быть 3 поля.
3. `while` + `awk` — формирует предложение для каждой записи:
   `Hello, my name is [Name]. I am [Age] years old and I live in [City].`

## Запуск
    ./task06_csv.sh data.csv

## Пример вывода
    [1] Исправляем файл (; → ,):
    Name,Age,City
    "Alice",25,"New York"
    ...

    [2] Проверка валидности (3 поля в каждой строке):
      Строка 2: 3 полей — OK
      ...

    [3] Предложения для каждой записи:
      Hello, my name is Alice. I am 25 years old and I live in New York.
      ...

## Что было сложного
- «Склейка» разорванной строки в CSV — нетривиальная задача;
  для домашки файл исправлен вручную.
- `tr` надёжнее `sed` для простой замены символов
  (нет слэшей — меньше шансов ошибиться).
- `awk -F','` не понимает кавычки — для простых данных без
  запятых внутри полей работает.
- `while IFS=',' read` — разбор CSV в цикле.
- Удаление кавычек из полей: `${var//\"/}`.

## Файлы
- `data.csv` — тестовые данные (исправленные вручную)
- `task06_csv.sh` — скрипт

# Задание 3: генератор отчётов из df -h

## Что делает
Скрипт `task03_df_report.sh` анализирует вывод `df -h`:

1. `awk` — оставляет только `Filesystem` и `Use%`, скрывает заголовок.
2. `sed` — убирает `%`, заменяет `/dev/` → `/device/`.
3. `for` — выводит предупреждение для ФС с использованием > 80%.

## Запуск
    ./task03_df_report.sh

## Особенность
`df -h` — динамический вывод (зависит от машины). Скрипт запускает
его внутри себя, использует временные файлы `/tmp/df_step*.txt`.

## Пример вывода
    [1] df -h: Filesystem + Use% (без заголовка):
    /dev/sdd 1%
    rootfs 1%
    ...

    [2] Без %, dev → device:
    /device/sdd 1
    rootfs 1
    ...

    [3] Предупреждения для ФС > 80%:
      Всё в порядке.

## Что было сложного
- `df -h` динамический — нельзя сохранить заранее
- `while read` с пробелами в путях ломается → `mapfile` + `for`
- `[ "$usage" -gt 80 ]` падает, если `$usage` пусто → `[[ =~ ^[0-9]+$ ]]`
- `s/dev/device/g` ломает `device` → `deviceice`, использован `s|/dev/|/device/|g`

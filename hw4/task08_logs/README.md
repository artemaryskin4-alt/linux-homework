# Задание 8: массовое создание файлов

## Что делает
Скрипт `task08_logs.sh`:

1. Создаёт директорию `logs`.
2. Через цикл `for` создаёт 10 файлов `log_01.txt` … `log_10.txt`,
   в каждый пишет `Это лог номер N`.
3. Выводит содержимое всех файлов через `cat` + цикл.
4. Удаляет файлы с чётными номерами (цикл + `if`).

## Запуск
    ./task08_logs.sh

## Пример вывода
    [2] Создаём 10 файлов log_01.txt ... log_10.txt:
      Создан: logs/log_01.txt
      ...
      Создан: logs/log_10.txt

    [3] Содержимое всех файлов:
    --- logs/log_01.txt ---
    Это лог номер 1
    ...

    [4] Удаляем файлы с чётными номерами:
      Удалён: logs/log_02.txt (номер 2 — чётный)
      ...

    [5] Осталось файлов:
    logs/log_01.txt
    logs/log_03.txt
    logs/log_05.txt
    logs/log_07.txt
    logs/log_09.txt

## Что было сложного
- Форматирование с ведущим нулём: `printf "%02d"` (1 → 01)
- Извлечение номера из имени: `basename`, `${var#prefix}`, `${var%suffix}`
- `$((10#num))` — принудительно десятичное (иначе `08` — ошибка)
- `shopt -s nullglob` — если glob не совпал, цикл не выполняется
  (иначе `$file` = буквально `logs/log_*.txt`)

## Файлы
- `task08_logs.sh` — скрипт
- `logs/` — результат (в `.gitignore`)

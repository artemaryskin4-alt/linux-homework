# Задание 5: анализ текстовых данных

## Что делает
Скрипт `task05_text.sh`:

1. `sed`/`tr` — приводит текст к нижнему регистру, удаляет знаки препинания.
2. `awk` — считает частоту слов, выводит ТОП-5 в формате `Слово: Количество`.
3. `for` + `curl` — запрашивает определения ТОП-5 слов в словарном API.

## Запуск
    ./task05_text.sh text.txt

## API
Используется `https://api.dictionaryapi.dev/api/v2/entries/en/<word>` —
бесплатный словарный API без ключа.

## Пример вывода
    [2] ТОП-5 самых частых слов:
      the: 10
      fox: 5
      dog: 5
      runs: 3
      quick: 3

    [3] Определения для ТОП-5 слов:
    === the ===
      With a comparative...
    === fox ===
      A red fox, small carnivore...
    ...

## Что было сложного
- `awk` не умеет сортировать → `sort -rn` снаружи
- `curl` к внешнему API — нужен интернет
- Парсинг JSON без `jq` — через `grep -oP`
- Обработка ошибок API (404 — слово не найдено)

## Файлы
- `text.txt` — тестовые данные
- `task05_text.sh` — скрипт
- `definitions/*.json` — ответы API (в .gitignore)

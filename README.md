# Домашние работы по Linux

Репозиторий с домашними заданиями по курсу Linux.
Каждое задание — в отдельной папке `hwN/` со своим README.

## Структура

| Папка | Задание | Что внутри |
|-------|---------|------------|
| `hw1/` | ДЗ-1: структура дома | `build_house.sh` — создаёт структуру дома |
| `hw2/` | ДЗ-2: практические задания | `class/` (в классе) и `home/` (дома) |
| `hw3/` | ДЗ-3: 7 bash-скриптов | Задачи 1–7 по темам курса |

## Подробности по заданиям

### hw1 — структура дома
Bash-скрипт, создающий структуру дома: 2 этажа, кухня, гостиная,
спальни, ванная, мебель с содержимым.

### hw2 — практические задания
- `class/` — 4 задания, разобранные в классе
- `home/` — 3 домашних задания

### hw3 — 7 bash-скриптов
1. `task01_check_csv` — проверка CSV/TSV на одинаковое число столбцов
2. `task02_backup_txt` — резервное копирование .txt с датой
3. `task03_top_words` — топ самых частых слов в файле
4. `task04_dir_report` — отчёт о файлах в директории
5. `task05_stud_marks` — студенты с оценкой выше порога по предметам
6. `task06_ping_hosts` — пинг списка хостов через цикл for
7. `task_07_star_animation` — обратный отсчёт с анимацией

## Требования

- Bash 4+
- GNU coreutils (find, sort, tr, seq, date)
- GNU grep с поддержкой PCRE (`grep -P`) — для hw3/task03
- ping — для hw3/task06

## Как запускать

Каждый скрипт — самостоятельный, запускается из своей папки:

```bash
cd hw3/task01_check_csv/
./check_file.sh good.csv

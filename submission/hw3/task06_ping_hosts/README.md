# Задание 6: пинг списка хостов через for

## Что делает
Скрипт `ping_hosts.sh` пингует список хостов (из файла или аргументов)
и выводит результат: доступен/недоступен + время отклика.

## Как запустить
    ./ping_hosts.sh <файл_со_списком>
    ./ping_hosts.sh host1 host2 host3 ...

## Переменные окружения
- `TIMEOUT=2`   — таймаут ожидания ответа в секундах (по умолчанию 1)
- `COUNT=1`     — сколько пакетов послать (по умолчанию 1)

## Пример вывода
    Пинг хостов (пакетов: 1, таймаут: 1s)
    Всего хостов: 7
    ============================================================
    ХОСТ                                 РЕЗУЛЬТАТ
    ------------------------------------------------------------
    8.8.8.8                               доступен (1.58 ms)
    google.com                            доступен (0.472 ms)
    no-such-host-xyz-123.invalid          недоступен
    ------------------------------------------------------------
    Доступно:   6
    Недоступно: 1
    Всего:      7

## Что было сложного
- Команда `ping` умеет висеть бесконечно → ограничили `-c 1 -W 1`
- Время отклика вытаскивается из вывода через `grep -oP 'time=\K...'`
- Чтение файла с пропуском пустых строк и комментариев (`#`)
- Защита от CRLF (Windows-переводы строк): `line="${line%$'\r'}"`
- Два режима в одном скрипте: файл или аргументы

## Файлы в папке
- `ping_hosts.sh` — основной скрипт
- `hosts.txt` — тестовый список хостов

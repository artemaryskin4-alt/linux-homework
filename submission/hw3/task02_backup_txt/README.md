# Задание 2: резервное копирование .txt с датой

## Что делает
Скрипт `backup_txt.sh` создаёт резервные копии всех .txt файлов
в директории, добавляя к имени дату.

## Как запустить
    ./backup_txt.sh [-r] [-t] [директория]

## Флаги
- `-r` — рекурсивно по подпапкам
- `-t` — добавлять к дате ещё и время

## Пример вывода
    notes.txt → backup/notes_2026-10-10.txt
    ⚠ Уже есть: notes_2026-10-10.txt — пропускаю
    Создано копий: 1, пропущено: 1

## Файлы в папке
- `backup_txt.sh` — основной скрипт
- `run_tests.sh` — автотесты
- `notes.txt` — тестовый файл

## Особенности
- Идемпотентность: повторный запуск не перезаписывает копии
- Рекурсия через `find -maxdepth`
- Дата в имени через `date +%Y-%m-%d`

# Домашние задания по Linux (WSL)

Сборник bash-скриптов, выполненных в рамках курса по Linux.
Каждое задание — в отдельной папке `taskNN_*` со своим README.

## Структура

| # | Задание | Папка | Основной скрипт |
|---|---------|-------|-----------------|
| 1 | Проверка CSV/TSV на одинаковое число столбцов | `task01_check_csv/` | `check_file.sh` |
| 2 | Резервное копирование .txt с датой | `task02_backup_txt/` | `backup_txt.sh` |
| 3 | Топ самых частых слов в файле | `task03_top_words/` | `top_words.sh` |
| 4 | Отчёт о файлах в директории | `task04_dir_report/` | `dir_report.sh` |
| 5 | Студенты с оценкой выше порога по предметам | `task05_stud_marks/` | `students_filter.sh` |
| 6 | Пинг списка хостов через цикл for | `task06_ping_hosts/` | `ping_hosts.sh` |
| 7 | Обратный отсчёт с анимацией | `task07_countdown/` | `countdown.sh` |

## Требования

- **Bash** 4+ (используются массивы, `[[ ]]`, `$'...'`)
- **GNU coreutils** (find, sort, tr, seq, stat, date)
- **GNU grep** с поддержкой PCRE (`grep -P`) — для задания 3
- **ping** — для задания 6 (в Ubuntu/Debian установлен по умолчанию)
- Локаль **UTF-8** (`C.utf8` или `C.UTF-8`) — для корректной работы с кириллицей

## Как запускать

Каждый скрипт — **самостоятельный** и запускается из своей папки:

```bash
cd ~/linux-hw3/taskNN_.../
./script.sh <аргументы>

Подробности, примеры и описание аргументов — в README.md соответствующей папки.

## Общие подходы в скриптах
  - set -euo pipefail — строгий режим bash: выход при ошибке, 
запрет неинициализированных переменных, падение пайпа при ошибке
любой команды в нём.

  - UTF-8-локаль — export LC_ALL=C.utf8 в скриптах, где
обрабатывается кириллица (иначе awk/grep рвут многобайтовые
последовательности).

   - Защита от CRLF — очистка \r из читаемых файлов
(line="${line%$'\r'}" или { sub(/\r$/, "") } в awk).
Файлы, созданные на Windows, ломают парсинг.

   - Переменные в кавычках — "$var", "${arr[@]}" — чтобы
пробелы и спецсимволы в путях не ломали команды.

   - Обработка ошибок — проверка наличия файла, валидация
аргументов, понятные сообщения через >&2.

   - Читаемый вывод — таблицы, заголовки, счётчики, иногда цвета.
